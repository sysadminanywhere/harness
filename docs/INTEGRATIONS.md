# Интеграции и границы продукта

## Стабильный локальный контракт

Harness Lab принимает локальную задачу через `/api/projects/:id/task`, сохраняет `taskId` и `runId`, ведёт очередь и возвращает состояние через `/state` и историю через `/runs`.

Локальные исполнители поддерживают только разрешённые адаптеры и безопасный allowlist команд. Отчёт конкретного запуска сохраняется в `.harness/runs/<runId>/report.md`.

## План адаптеров

1. GitHub Issues — импорт задач и ссылки на issue без автоматической публикации результата.
2. Linear — импорт/синхронизация статусов после явного подтверждения пользователя.
3. CSV/JSON — перенос задач и истории без внешней авторизации.

Каждый адаптер должен иметь dry-run и явное подтверждение записи наружу, сохранять внешний идентификатор, быть ограничен policy проекта и иметь негативные тесты повторной доставки и конфликтов revision.

## Границы

Локальные проверки не подтверждают production-публикацию, доступ к произвольным внешним аккаунтам, коммерческий пилот или принятие заказчиком. Реальный Codex start/tool/pause/resume проверен отдельными probes, указанными в IMPLEMENTATION_AUDIT.md; это не означает успешную реализацию прикладных задач HCM.
