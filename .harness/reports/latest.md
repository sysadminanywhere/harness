# Автоматическое обновление процессов

Доска получает свежий план, очередь, статусы, запуски и события каждые 2 секунды. Открытый отчёт обновляется вместе с журналом, сохраняя фильтры и выбранный запуск. Добавлены индикатор последнего обновления, сообщение об ошибке связи и автоматические повторные попытки. При возвращении на вкладку, фокусе окна и восстановлении сети выполняется обновление.

Защита: нет параллельных циклов синхронизации; запрос ограничен 10 секундами; запоздавшие ответы другого проекта или до сохранения отбрасываются; синхронизация откладывается во время ввода в диалогах, сохранения и перетаскивания.

## Проверки

- npm test: PASS (синтаксис и HARNESS_SMOKE_OK).
- git diff --check: PASS.
- Playwright в изолированном временном workspace, порт 43174: PASS. Внешняя карточка появляется без перезагрузки; изменения карточки применяются; несохранённый текст формы сохраняется; после закрытия формы синхронизация возобновляется; отчёт и события обновляются; после HTTP 503 виден сбой связи и автоматическое восстановление; фильтры отчёта сохраняются.
