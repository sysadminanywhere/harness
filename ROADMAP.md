# Harness Mission Control — живая дорожная карта

Цель проекта: локальный канбан для управления несколькими проектами и прозрачного взаимодействия с Codex через файлы `.harness`. Внешние AI API и API-ключи не используются.

## Завершено

- [x] Локальный Node-сервер и запуск на Windows без `.sh`.
- [x] Реестр проектов, переключение и отдельный `.harness` для каждого проекта.
- [x] Канбан: создание, редактирование, drag-and-drop и удаление карточек.
- [x] Файловый мост: `current-task.md`, `status.json`, `events.jsonl`, `requests/`, `reports/latest.md`.
- [x] Инструкция `AGENTS.md` с резервной копией существующих инструкций.
- [x] Синхронизация отчёта Codex и автоматические переходы в «Проверка»/«Заблокировано».
- [x] Контрольная точка для высокоприоритетных задач.
- [x] Локальный планировщик без внешних API.
- [x] Управление активной задачей: пауза, продолжение, отмена, повтор, возврат в работу и подтверждение результата.
- [x] Playwright-проверка основных сценариев и отсутствие ошибок консоли.

## Правило завершения

После каждого среза запускать релевантные проверки, добавлять изменённые файлы в Git staging и переходить к следующему незавершённому пункту. Пункт можно отметить выполненным только после подтверждения работающим тестом или браузерным сценарием.
